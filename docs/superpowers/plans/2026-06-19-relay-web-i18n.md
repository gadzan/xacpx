# relay-web Internationalization (i18n) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add full English + Simplified-Chinese (zh-CN) internationalization to the relay-web dashboard, with browser-language auto-detection, a persisted user override, and a language switcher in Settings.

**Architecture:** Introduce `vue-i18n` v9 in Composition API mode (`legacy: false`, `globalInjection: true`) so `$t()` works in every template. A new Pinia `locale` store mirrors the existing `theme` store (localStorage `relay-locale`, fallback to `navigator.language`, fallback to `en`) and is the single source of truth that drives `i18n.global.locale`. Each component's user-facing strings move into per-namespace message catalogs (`en` and `zh-CN`), co-located with the migration task that introduces them so the catalog never drifts from usage. Server-supplied text (`NoticeToast.text`, `ToolStepCard.error`) and short internal error codes stay as-is (out of scope).

**Tech Stack:** Vue 3.5 (`<script setup>`), Pinia 2, vue-i18n 9, Vite 5, Vitest 2 + @vue/test-utils 2, TypeScript (strict via `vue-tsc`).

**Working directory:** All paths below are relative to `packages/relay-web/` unless noted. Repo root is `/Users/maijiazhen/Projects/weacpx-github`.

**Conventions for every task:**
- Run commands from the repo root.
- Typecheck: `cd packages/relay-web && npx vue-tsc --noEmit` (or `bun run --cwd packages/relay-web build` for the full build).
- Test a single file: `bun run --cwd packages/relay-web test -- src/__tests__/<file>.test.ts` (vitest). Test all: `bun run --cwd packages/relay-web test`.
- Commit only the files you touched. NEVER `git add -A` / `git add .`. NEVER stage `bun.lock`, `dist/`, or `node_modules/` unless the task explicitly says so (Task 1 intentionally stages `package.json` + `bun.lock` for the new dependency).
- English message values MUST be byte-for-byte identical to the current hardcoded English so existing literal-text test assertions keep passing once i18n is installed globally in tests (Task 1 wires that).

```ts
import { createI18n } from "vue-i18n";
import en from "./messages/en.ts";
import zhCN from "./messages/zh-CN.ts";

export const SUPPORTED_LOCALES = ["en", "zh-CN"] as const;
export type AppLocale = (typeof SUPPORTED_LOCALES)[number];

export const DEFAULT_LOCALE: AppLocale = "en";

/** Map a raw BCP-47 tag (e.g. navigator.language "zh-Hans-CN") to a supported
 *  locale. Anything starting with "zh" → zh-CN; everything else → en. */
export function resolveLocale(tag: string | undefined | null): AppLocale {
  if (tag && tag.toLowerCase().startsWith("zh")) return "zh-CN";
  return "en";
}

export const i18n = createI18n({
  legacy: false,
  globalInjection: true,
  locale: DEFAULT_LOCALE,
  fallbackLocale: "en",
  messages: { en, "zh-CN": zhCN },
});
```

```ts
import { defineStore } from "pinia";
import { ref } from "vue";
import { i18n, resolveLocale, SUPPORTED_LOCALES, type AppLocale } from "../i18n";

const KEY = "relay-locale";

function initialLocale(): AppLocale {
  const saved = localStorage.getItem(KEY);
  if (saved && (SUPPORTED_LOCALES as readonly string[]).includes(saved)) {
    return saved as AppLocale;
  }
  return resolveLocale(navigator?.language);
}

export const useLocaleStore = defineStore("locale", () => {
  const locale = ref<AppLocale>(initialLocale());
  function apply() {
    i18n.global.locale.value = locale.value;
    document.documentElement.lang = locale.value;
  }
  function set(next: AppLocale) {
    locale.value = next;
    localStorage.setItem(KEY, next);
    apply();
  }
  apply();
  return { locale, set };
});
```

- [ ] **Step 3: Implement the helpers**

Create `src/lib/format.ts`:
```ts
import { i18n } from "../i18n";

/** Active BCP-47 locale string for Intl formatters. */
function activeLocale(): string {
  return i18n.global.locale.value;
}

/** Compact local time, e.g. "15:45". Empty string for missing/invalid input. */
export function fmtTime(iso?: string): string {
  if (!iso) return "";
  const d = new Date(iso);
  return Number.isNaN(d.getTime())
    ? ""
    : d.toLocaleTimeString(activeLocale(), { hour: "2-digit", minute: "2-digit" });
}

/** Full local date+time. Empty string for missing/invalid input. */
export function fmtDateTime(iso?: string): string {
  if (!iso) return "";
  const d = new Date(iso);
```
