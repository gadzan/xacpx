WP-13 DialogShell + z-index ladder
==================================

Scope: one modal shell for the centred dialogs, plus a named overlay ladder.
Composer animation, widths and protocols untouched. No production deployment.

Shell
-----
src/components/DialogShell.vue (new)
- scrim (bg-scrim + blur), panel glass, focus trap / Esc / focus restore via use-modal-a11y
- panel styling stays with the caller (panel-class): widths differ by intent
- root is a plain element; callers that must escape a transformed ancestor wrap
  <Teleport to="body"> themselves (keeps the shell testable in place, and keeps
  a stubbed Teleport in unit tests from swallowing the frame)
- props: label | labelledby, panel-class, data-test, level, safe-area, blur-class,
  initial-focus; expose: panel, focusChild(selector)
- @close is the only close path. Passing navigateBack as the close handler
  self-recurses: navigateBack closes the top layer, whose close handler is the
  shell, which calls navigateBack again -> stack overflow.

z-index ladder (tailwind.config.js -> theme.extend.zIndex)
----------------------------------------------------------
z-sheet          40   MobileSheet default (was a literal z-40 in two places)
z-dialog         50   a modal dialog
z-dialog-nested  60   a dialog opened from a dialog (picker, removal confirm);
                      also TraceOverlay's mobile sheet (was z-[60])
z-dialog-top     70   must beat a drawer or sheet stack (ForkTopicDialog, was z-[70])
z-confirm       100   global confirm queue (ConfirmDialog, was z-[100])
